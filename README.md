# LoRaWAN-Smart-Farm
LoRaWAN smart irrigation system developed as a BSc Thesis. It features an Arduino MKR WAN 1310 environmental sensor node and an ESP32-actuated motorized ball valve that autonomously triggers watering cycles based on real-time soil moisture data. The full telemetry pipeline integrates The Things Network (TTN), MQTT, InfluxDB, and Grafana.
